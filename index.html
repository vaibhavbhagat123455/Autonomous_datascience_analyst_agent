Anti-Hallucination Grounding

Standard LLM code generation crashes when the LLM invents column names. In our system, the Data Profiler first computes real schema types, which are injected into a strict Pydantic v2 OrchestratorPlan contract. Any invalid column name causes immediate validation halts.

Singleton Noise Pruning

Real-world datasets contain single-instance corrupt labels (e.g., malformed JSON fragments) that trigger fatal exceptions in scikit-learn stratified splits. Our Data Cleaner automatically prunes classes with count < 2.
